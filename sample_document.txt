ContextIQ Product Overview
ContextIQ is a document question-answering assistant. Users upload PDF, TXT, or Markdown files. The backend extracts text, splits it into overlapping segments, and retrieves relevant passages using token-frequency scoring. LangGraph orchestrates retrieval and answer generation. If an OpenAI API key is configured, the system uses an OpenAI chat model to produce answers grounded in the retrieved excerpts. Without an API key, it provides relevant excerpts instead.
The application is intended for document exploration, onboarding, internal knowledge search, and research. It supports PDF and text uploads, document deletion, source excerpts, and responsive layouts.
Important limitations: uploaded files are held in server memory and disappear on restart. Retrieval uses lexical scoring rather than vector embeddings. There is no authentication or multi-tenant isolation. For production, add persistent storage, access controls, embedding-based retrieval, rate limiting, and evaluation tests.
